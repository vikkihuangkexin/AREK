# Source provenance and repository preparation

- [source_lineage.tsv](source_lineage.tsv) maps recovered originals to the included implementations, preserving original hashes.
- [recovered_code_index.tsv](recovered_code_index.tsv) indexes historical code, including routes not ported as active modules.
- [repository_preparation.json](repository_preparation.json) records the supplied archive identity, retained and adapted files, excluded categories, and scope of this GitHub release.

The original Biomni archive retains its full-data `AC/demo/`, raw acquisition manifest, source-object inventory, and detailed validation receipts. These data and long run logs are not copied into the public code release. Acquisition URLs are provenance and do not establish downloaded reads.

Aliases M1, CLIN, V2, V3, and RECOVERY identify original roots; they are not default output locations. Run the 22 documented scripts or `run.py`. Historical source locations in index tables remain provenance rather than alternative executable entries.

The original presentation narrative and assets remain external. Repository code and documentation are English; runtime reconstruction preserves the supplied narrative. Original specimen identities and source values are not translated or relabeled.
